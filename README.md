# ☁️ Azure-Based Weather Prediction Model  

## 📌 Project Overview  
This project utilizes **Microsoft Azure AI services** to predict weather conditions based on **historical datasets**. Using **Azure Machine Learning Studio, AutoML, and Cognitive Services**, we developed and deployed an AI model that forecasts future weather patterns.  

## 🔍 Key Features  
✅ **Built with Azure ML Studio** – No-code & low-code machine learning model.  
✅ **Trained on Kaggle weather datasets** for real-world accuracy.  
✅ **Integrated AutoML** for selecting the best model.  
✅ **Tested & deployed model for real-time predictions.**  

## 🛠️ Tools & Technologies Used  
- ☁ **Azure Machine Learning Studio** – Model development & deployment.  
- 📊 **Azure Time Series Insights** – Analyzing historical weather trends.  
- 🧠 **Azure Cognitive Services** – Feature extraction & data processing.
